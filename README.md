# My Draft Strategist 🏈

A lightweight, mobile-optimized fantasy football draft companion built to streamline custom rankings, tier tracking, live Sleeper syncing, and draft management.

## Features
- **Custom Rankings & Tiers:** Upload CSV or Excel sheets with automatic team and bye-week parsing.
- **On-the-Fly Editing:** Easily adjust player ranks and tiers directly on the board.
- **Sleeper Sync:** Connects to your Sleeper draft ID for live auto-syncing of drafted players.
- **Stack Highlighting:** Automatically highlights correlated QBs and pass-catchers.
- **Market Values / ADP:** Powered by the [LeagueLogs API](https://leaguelogs.com).
